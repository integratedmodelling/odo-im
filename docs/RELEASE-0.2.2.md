# ODO 0.2.2

Adds abstract Frequency under IntensivePhysicalProperty, annotated with Hz.
Frequency measures completed cycles per unit time. The worldview establishes
its cyclic-process bearer; arbitrary event occurrence rates are separate.
Duration and existing releases are unchanged. This adds no time/space taxonomy,
cycle individuals, numerical reciprocal rule or contextualization machinery.

The paired language classification keeps Duration intensive, matching ODO.
Ordinary event duration remains valid; quantitative within expressions require
extensive physical-property ancestry and do not admit Duration or Period.
